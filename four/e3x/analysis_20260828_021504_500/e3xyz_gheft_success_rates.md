# GHEFT Paired-Seed Success Rates

## Definitions

- Performance retention: `GHEFT makespan < DHEFT makespan` for the same seed.
- Resource saving: `GHEFT used vCPUs < NHEFT used vCPUs` for the same seed.
- Joint success: both strict conditions hold for the same seed.
- Ties are not counted as successes.
- Each 95% CI is a 10,000-resample percentile bootstrap interval for the paired-seed success rate.
